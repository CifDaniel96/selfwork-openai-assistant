# Travel Assistant

Travel Assistant è un assistente AI sviluppato come selfwork della specializzazione **Agentic AI & Python**.

Il progetto utilizza la **OpenAI Responses API** con una knowledge base dedicata ai viaggi e permette di mantenere il contesto della conversazione.

## Funzionalità

- ricerca di informazioni tramite `file_search`
- itinerari e consigli di viaggio
- confronto tra destinazioni
- gestione dei follow-up conversazionali
- invio di itinerari via email tramite Resend
- interfaccia chat realizzata con Chainlit

## Tecnologie utilizzate

- Python
- Poetry
- OpenAI Responses API
- Conversations
- Vector Store e File Search
- Resend
- Chainlit
